# 减少重复整理和往返

默认两次批量工具操作：prepare 生成全批上下文与精简工作单；代理一次实际看图后，complete 同一锁内登记、规划、判阈值、渲染、自动校验和冻结。不逐镜调用工具，不重复 context、规划、预检或渲染。

## 准备与阅读

一次保存完整原脚本、逐镜原文、资产和时长来源。精简 INPUT 省去固定字段与空数组；purpose 与 required_result 相同就复用，阶段与关键状态仍单独判断。共同 requirements_template 按明确 scope 写一次，各镜显式引用，不跨时空套用。只写状态种子和实际变化，由程序计算完整状态。

按阶段读取：准备查图片接口与要求；校对查精简图片规则；分组查规划；阈值触发才查提示词规则、分析原提示词及填写资产风格。已读且未变的规则复用，不提前读无关资料。

visible_facts 一次记录，须足以支持身份、阶段与七项检查。PASS 不扩写问题与建议，由程序写“符合脚本”；FAIL／uncertain 保留具体原因，省图保留双侧依据。工具复用的是事实和机械字段，不是自动批准。

## 缓存与交付

一次操作内缓存图片信息、哈希及上下文，结束前重验全部依赖内容。输入改变就失效；不能用缓存结论批准新图片。原图细节不清时放大查看，不靠缩略图猜关键关系。

交付格式 3 自动核对表格全部九列、原图对应／哈希／链接、缩略图预览、镜序及文件集合。成功直接交付，省去第二次人工整表与图片核对；失败或刚修改渲染／规则才定位检查。初次实际看图仍完整进行，旧交付冻结、修订另存。

## 触发后的提示词

原提示词 prepare 只记路径，达到阈值才打开、登记并筛选。未达阈值不做这部分准备。缺项只影响提示词，审查报告照常完成。

complete 已输出 PROMPT.view.json／PROMPT.json 就直接阅读填写，不再 prepare。全镜来源视图合并重复贡献，plan_version=2 仅写必要 edits、来源处理 notes 和九项具体结论。全镜核对一次完成，清楚且已覆盖的原正文保留，不拆九轮重读或逐镜调用。finish 重建来源一次、集中汇总错误后导出。

## 耗时与环境

记录总墙钟及准备、视觉审查、收尾、提示词阶段的实际起止。工具报告只代表工具时间，不包含代理阅读、提取和判断；无打点不能推算各步骤。剔除压缩上下文时间时用实际记录的压缩区间，报告原始间隔、剔除值与净耗时。尚未实测不承诺提速比例。

复用可用 Python 3.10+ 与 Pillow，Windows 使用 PYTHONUTF8=1 并固定解释器路径。缺模块仅补缺项，不在每个项目重复探测、下载或安装运行环境。当前检查入口为 tests/run_checks.ps1，不依赖媒体工具。
