# 图片审查规则

图片校对只读本文件，其他阶段规则按需读取。接口及工作单字段见 [图片入口](storyboard-images.md#一次整批审查)，要求的来源与状态计算见 [镜头要求](shot-requirements.md)。输入原生成提示词在达到阈值后才读取，不用于本轮审查。

## 一次看图，一次记录

新任务在 overview 后立即批量显示首看拼图；本轮每张分镜只看一次。按原脚本同时判断三组：主体内容（identity/scene/props）、状态承接（key_state/continuity）、参考可用性（composition/cleanliness）。三级放宽也在同一次观察中完成：1允许景别/拍摄角度差异；2允许合理动作阶段/光影差异；3允许非关键细节差异。每级按下述画外规则判断必要关系，不要求全部道具与落脚处入画；可见关键矛盾及脚本明确的角色朝向错误不能被其他相似元素抵消。已配对输入不重新选帧。

将实际可见事实保存到 OBSERVATIONS.json。prepare --reuse-overviews 验证脚本、镜序和图片后自动带入工作单；已有事实用于明确判断，不再次开图，事实本身不会自动变成 PASS。中断或已准备任务按需读 REVIEW.pageNNN.json。新包 images_to_open 只有本页分镜总览，不生成资产拼图、不重开前页末镜；连续性复用保存的相邻 visible_facts。旧包保留历史结构，采用本轮一次看图要求时只显示未看分镜。

新任务用 --concise 生成版本4工作单，verdict 明确覆盖三组，显式填写 reference_phase、match_level，复用 visible_facts。FAIL 只在 findings 写一次脚本矛盾、修正和错误种类；uncertain 只在 unresolved 写一次必要疑点。程序机械展开七项、问题与返修依据，不从事实或空字段自动推定通过；省图仍须另外明确 reference 双侧依据和理由。每页及时保存，已完成记录不重做，不放大或排复查。版本1/2/3兼容。

在 Codex 工具层，一次 functions.exec 可读取审查包，再并发加载图片，按原顺序显示（替换为真实绝对路径，不执行本示例占位符）：

```javascript
const r = await tools.exec_command({cmd: "Get-Content -Raw -LiteralPath 'ABS_BATCH_JSON'", max_output_tokens: 12000});
if (r.exit_code !== 0) throw new Error(r.output);
const view = JSON.parse(r.output);
text(view);
const targets = view.images_to_open;
const loaded = await Promise.allSettled(targets.map(t => tools.view_image({path: t.path, detail: "original"})));
for (let i = 0; i < loaded.length; i++) {
  if (loaded[i].status !== "fulfilled") throw new Error("图片加载失败：" + targets[i].path);
  text(targets[i]);
  image(loaded[i].value.image_url, "original");
}
```

targets 只保留未看过的分镜页；首看记录已复用的页不再显示。每页原始尺寸显示一次，工具并发加载只减少等待，视觉结论仍逐镜产生。

| 结论 | 标准与记录 |
| --- | --- |
| PASS | 脚本的必要人物、动作、关系及该参考阶段的状态成立；动作／姿态正确且道具或落脚处在画外的情形可通过。报告问题栏只写“符合脚本”，不追加允许差异的解释或修改建议。 |
| FAIL | 同镜可见事实与必要剧情矛盾、角色明确朝向错误，或严重损坏妨碍必要内容辨认。保留原文、实际观察、问题及具体修正；按需读 [返修证据](repair-assessments.md)。 |
| uncertain | 除可接受的画外裁切外，剧情必需的信息看不清，或阶段／脚本要求的朝向不能确定。保留“—／暂不省图”，写具体需确认的信息后直接交付，不自动放大或澄清。 |

不由空字段、文件名、模板或工具成功推定 PASS。输入数量、镜号对应、文件打不开属于输入问题，不计剧情错误。不要为让图片通过改写脚本要求。

## 过程帧与完成帧

参考图可以呈现动作或转场的入口、中间过程或完成状态。先根据可见事实与上下文判断阶段，再检查该阶段的必要关系；不能把完整镜头的最终结果当成每一张参考静帧的必需条件。脚本中的“填满、消失、交给、站稳”等结果描述本身，不等于指定这张参考图必须是完成帧。

对渐白、渐隐、溶解、遮挡、变形、交接等过程，只要画面是该过程合理的可见阶段，人物、对象及因果关系成立，且不破坏剧情，允许原人物、场景或前一状态暂时残留，按 entry 或 action 判 PASS。无需为“还没完成”单独要求确认、降为 uncertain 或提出返修；同时不能声称一张图已经验证完整运动。

当脚本明确指定这张参考图为完成帧／最终状态、关键剧情要求此时已经完成，或图中出现与任何合理阶段都矛盾的身份、对象、方向、空间及因果关系时，以对应要求判 FAIL。角色朝向另按下述规则检查，不能以普通角度差异放过方向错误。必要关系看不清或阶段确实无法确定，直接保留 uncertain，不放大。不能凭“可以继续动”放过真正的剧情矛盾。

例如白光正在吞没房间时，人脸和室内轮廓仍可辨，作为渐白过程帧应通过；脚本指定该图为“最后一帧必须纯白，不能有轮廓”时，同一张图才不符合。钥匙交接中双方短暂接触同一把钥匙可通过；明确交接完成后仍由错误角色持有则不符合。

若冲突来自代理把最终结果误提取为所有阶段的 must_have，按[镜头要求](shot-requirements.md#整理阶段的要求前置自检)修正阶段及要求版本、更新来源并重建受影响上下文；保留原脚本和完整结果。不能把提取错误变成图片问题，也不能沿用失效的证据绑定直接放行。

## 参考阶段与剧情约束

完整镜头动作保留在脚本；静帧按 entry／action／exit 阶段检查。交接前仍由交出者持钥匙可合理，明确交接完成却持物者错误则 FAIL。单图不能证明运动本身不构成失败或待核查；阶段未知不得 PASS。相邻图片核对可见连续性，不要求证明中间运动轨迹。

构图检查脚本的动作、人物及必要关系。普通景别、站位、拍摄视角、姿态等合理差异不改变剧情时可通过，角色朝向错误除外。普通脸型、服装颜色和材质偏差不自动判错；须识别行动主体，保留脚本的关键身份、伪装、换装等剧情线索，不另设通用的严格外观复刻条件。

### 画外内容与角色朝向

- **画外可通过。** 脚本要求的动作／姿态正确，道具或支撑位置因裁切在画外，且没有可见矛盾时，props／scene／composition 可以 PASS，不仅因未入画而记 uncertain。高举动作正确、奖杯在上方画外，或站立姿态合理、木箱与脚在下方画外，均可通过；无需额外找图证明画外物体存在。visible_facts 只写看到的动作、裁切与位置，画外关系沿用脚本，不写成亲眼看见奖杯或木箱。
- **可见矛盾仍不通过。** 若画面清楚显示本该持物的手为空、拿成另一关键道具，或完整落脚处显示站在地面而不是脚本的木箱上，按可见矛盾 FAIL，不能借画外规则放行。辨不清关键动作或关系仍 uncertain。
- **朝向错误不通过。** 脚本明确角色面向／背向的对象或方向，画面明确相反时 FAIL，即使其余剧情元素正确也不放宽。普通方向错误按 composition 记录脚本引文、实际朝向与修正；若同时破坏剧情状态或因果，再按实际影响记录，不自动升级为关键错误。
- **区分角色朝向和机位。** 以脚本的门、人物、镜头等参照物判断身体／头脸朝向；反打造成的画面左右变化、机位变化或单纯眼神变化，不直接等于角色朝向错误。脚本未写方向不新增要求；已写但确实看不清时 uncertain，不臆造 FAIL 或 PASS。

默认不检查屏幕文字，不作 OCR 或逐字比对，不检查对白原文、配音或口型同步；对白的剧情含义仍帮助理解必要人物、动作及结果。cleanliness 只检查妨碍理解必要内容的画面缺陷，不追加审美要求。

## 资产对照与省图

asset_comparisons 默认空，不做逐镜原资产外观对照、不生成资产拼图。直接可见的脚本人物/场景/道具矛盾以本镜脚本和原图定位，不要求额外资产对照才能 FAIL。只有用户明确要求原资产外观对照时才补。同镜、同资产、同方面的观察须绑定原资产及本镜原图；人物问题说明具体 story_requirement 和 story_impact，不能只写“衣服不同”。先考虑光照、雨水、角度、遮挡和模糊。场景、道具差异须结合脚本剧情判断，装饰差异不单独判错。资产问题的 issues 引用对应 asset_ids 和 asset_comparison_ids，非资产问题填空列表。

省图先沿用已确定分组，只在合法组内判断。要求同组双侧 PASS 且保留的原图锚点、当前原资产及状态依据；不循环推导，保护首尾、关键变化和必要锚点。ai_fill 明确记录两个依据镜号及理由，仍标“建议省图，未验证”。FAIL／uncertain 暂不省图。所有镜头和原图继续展示、链接、保存。

## 到交付即停止

完成工作单后运行 complete；新报告自动校验九列内容与当前脚本、审查及取舍一致，检查逐镜原图、缩略图、链接、顺序、覆盖和文件哈希。成功即交付，不再人工逐镜重看报告与图片。校验失败、渲染模板或规则刚修改时才定位受影响部分，不因字段错误重看图片；最初的逐镜视觉审查与提示词语义核对仍保留。旧冻结交付不改写，不声称补做了它原来没有的校验。
