# 图片审查规则

图片校对只读本文件，其他阶段规则按需读取。接口及工作单字段见 [图片入口](storyboard-images.md#一次整批审查)，要求的来源与状态计算见 [镜头要求](shot-requirements.md)。输入原生成提示词在达到阈值后才读取，不用于本轮审查。

## 一次看图，一次记录

先读该镜脚本、已解析要求、相关原资产和对应原图，判断是否符合该镜脚本、适合作为生成参考。每镜显式完成 identity、scene、props、composition、action、continuity、cleanliness 七项检查，以及参考阶段、结论和图片取舍。逐镜 visible_facts 只写一次，需支持人物、阶段及相关判断；程序复用到内部观察和理由。有必要时另写针对性说明。

| 结论 | 标准与记录 |
| --- | --- |
| PASS | 必要人物、道具、场景关系及该参考阶段的状态成立。报告问题栏只写“符合脚本”，不追加允许差异的解释或修改建议。 |
| FAIL | 同镜可见事实与必要剧情或明确严格要求矛盾，或严重损坏妨碍必要内容辨认。保留原文、实际观察、问题及具体修正；按需读 [返修证据](repair-assessments.md)。 |
| uncertain | 剧情必需的信息看不清或阶段不能确定。先放大原图或集中澄清，未解决时保留“—／暂不省图”，写具体需确认的信息。 |

不由空字段、文件名、模板或工具成功推定 PASS。输入数量、镜号对应、文件打不开属于输入问题，不计剧情错误。不要为让图片通过改写脚本要求。

## 参考阶段与剧情约束

完整镜头动作保留在脚本；静帧按 entry／action／exit 阶段检查。交接前仍由交出者持钥匙可合理，明确交接完成却持物者错误则 FAIL。单图不能证明运动本身不构成失败或待核查；阶段未知不得 PASS。相邻图片核对可见连续性，不要求证明中间运动轨迹。

构图检查必要人物、道具及空间关系是否可见。景别、站位、视角、姿态等合理差异不改变剧情时可通过；必要信息被裁掉、遮挡则按同镜证据判断。画外或局部特写不等于道具消失。普通脸型、服装颜色和材质偏差不自动判错；须识别行动主体，保留关键身份、伪装、换装等剧情线索和用户明确严格要求。

默认不检查屏幕文字，不作 OCR 或逐字比对，不检查对白原文、配音或口型同步；对白的剧情含义仍帮助理解必要人物、动作及结果。cleanliness 只检查妨碍理解必要内容的画面缺陷，不追加审美要求。

## 资产对照与省图

asset_comparisons 默认空，只有剧情相关差异或问题才补。同镜、同资产、同方面的观察须绑定原资产及本镜原图；人物问题说明具体 story_requirement 和 story_impact，不能只写“衣服不同”。先考虑光照、雨水、角度、遮挡和模糊。场景、道具差异也须影响剧情或明确严格要求，装饰差异不单独判错。资产问题的 issues 引用对应 asset_ids 和 asset_comparison_ids，非资产问题填空列表。

省图先沿用已确定分组，只在合法组内判断。要求同组双侧 PASS 且保留的原图锚点、当前原资产及状态依据；不循环推导，保护首尾、关键变化和必要锚点。ai_fill 明确记录两个依据镜号及理由，仍标“建议省图，未验证”。FAIL／uncertain 暂不省图。所有镜头和原图继续展示、链接、保存。

## 到交付即停止

完成工作单后运行 complete；新报告自动校验九列内容与当前脚本、审查及取舍一致，检查逐镜原图、缩略图、链接、顺序、覆盖和文件哈希。成功即交付，不再人工逐镜重看报告与图片。校验失败、渲染模板或规则刚修改时才定位受影响部分，必要时看图；最初的逐镜视觉审查与提示词语义核对仍保留。旧冻结交付不改写，不声称补做了它原来没有的校验。
