# AI 分镜校对 Skill

这是一个帮你检查 AI 预演视频的 Skill。

它会把视频和你的分镜脚本、人物图、场景图、道具图放在一起对照，检查：

- 画面是不是演对了脚本
- 前后镜头的人物、服装、位置和道具是否接得上
- 有没有漏镜、乱序、错误转场或多出剧情

最后给你一份带小分镜图的 Markdown 报告，方便直接阅读和修改。

这个版本按用户事先给出的授权运行：问题达到返修条件时，最多自动付费返修一次。如果这次只想看报告，明确说“不要返修”即可。

## 你需要准备什么

最少准备三类东西：

1. 一段已经生成的 AI 智能镜头视频
2. 按顺序写好的分镜脚本，最好带镜号、画面内容、动作、结果和时长
3. 相关资产图，例如人物、场景、道具和关键状态图

如果你还留着**生成这段视频时用的原提示词**，也可以一并提供（直接粘贴，或给 TXT/MD 文件）。没有也能正常审查。

## 它会怎么工作

1. 检查文件是否齐全，并给视频建立可追溯的时间和画面指纹。
2. 抽帧并按镜号对照脚本和资产图。
3. 分三层检查：单个镜头、相邻镜头、整段故事。
4. 逐镜记录检查结果和依据。看不清的地方会说明缺什么证据、该补看哪里。
5. 保留原镜头编号和顺序，只合并同一剧情段里的相邻镜头，每组计划时长为 4–15 秒。
6. 输出 Markdown 报告和小分镜图。

## 输出什么

你会得到：

- `01_原视频审查.md`：原视频的审查结果
- `images/`：报告中使用的小分镜图
- 两张表：分组结果、逐镜审查结果

每个镜头都会保留。确认漏镜后，会标出“必要漏镜”，或在证据充分时建议“可推导生成”。
原视频里已经有、并且审查通过的镜头，即使建议省去独立参考图，也会保留抽帧缩略图和原图链接；只有确认漏镜且通过省图判断时，才显示“可推导生成”文字，不伪造图片。

## 什么时候会返修

新项目最多自动付费返修一次，不会因为有多个视频分组就反复提交。

确认问题达到返修条件、准备检查通过且额度允许，并且你这次没有要求“只审查”时，才会返修相应视频。提交失败或结果不明也算用过这次机会，不会自动再次花钱；旧项目原有的预算和零额度限制仍有效。返修沿用输入视频的画幅，完成后重新检查新视频和前后衔接。发给视频模型的提示词只描述脚本里已有的画面动作；如果关键剧情只能靠对白表达、无法改成已有画面，就会停止返修并说明原因。

提供了原提示词时，返修会参考其中与脚本相符的画面细节；冲突或重复的内容不会照搬。原提示词不会改变视频审查结论，也不能覆盖脚本、镜头顺序和无声无字幕要求。

返修前，每个确认失败或漏镜都必须写清楚：脚本中哪句话证明有问题、问题会造成什么影响、准备怎么改。依据不完整时，系统会停在报告阶段，不提交返修任务。

如果处理中断，可以从已经校验过的检查点继续，不必重复提交。已经交付的结果需要补正时，会在新目录生成关联修订，并保留旧结果。

## 你可以这样对它说

```text
请检查这个 AI 预演视频。
视频：D:\\project\\previs.mp4
脚本：D:\\project\\script.md
资产图：D:\\project\\assets\\

先完成原视频审查，输出 Markdown 和小分镜图。不要生成视频，也不要返修。
```

如果希望按已授权的额度自动返修，可以这样说：

```text
达到返修条件时，请对有问题的来源视频返修一次。返修后重新检查，并保留原结果；如果仍有问题，请先看报告，不要自动连续提交。
```

## 需要知道的限制

- 找到一张相似的帧，不代表整个镜头已经通过。
- 抽帧看不清的动作或转场，会写明证据缺口和补查方向，不会假装已经确认。
- 某段剧情如果不足 4 秒，且无法在不跨剧情边界的情况下合并，报告会说明分组未完成，需要补充内容或调整计划时长。
- 普通的脸型、颜色或材质差异不会单独判失败，除非影响剧情或连续性。
- 没有现成视频时，可以整理脚本和资产，但不能凭空证明视频内容正确。
- 字幕、台词、口型和声音是否正确，默认不做完整校对。

## 开发者检查

在仓库根目录运行：

```powershell
powershell -ExecutionPolicy Bypass -File tests/run_checks.ps1
```

这会检查 Skill 结构、脚本接口、审查规则和交付流程。
