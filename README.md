# AI 分镜实证规划 Skill

`ai-storyboard-previs` 用已有视频校对分镜脚本。它把视频抽帧与脚本、角色/场景/道具资产图对应起来，按视频组检查画面和连续性，再给出相邻镜头的聚合与 `ai_fill` 省图建议。

默认流程是：**整理输入 → 登记已有视频 → 批量抽帧匹配 → 组级审查 → 相邻镜头聚合 → 输出图片和 Markdown**。

默认不会生成视频，也不会自动生成或修复分镜图。视频是需要核对的实证来源，资产图只用于身份、外观、场景和道具比对，不会被上传。

## 输入

给 Skill 提供三类材料：

1. **已有视频**：需要校对的预演或样片。可以是一段视频，也可以是多段视频；每段视频会登记为一个来源组。
2. **有序分镜脚本**：每个镜头的原始编号、画面描述、时长，以及关键动作的起态和结果。Skill 保留编号、顺序和剧情，不用错误画面反写脚本。
3. **资产图**：角色、场景、道具及简短说明，用来检查人物身份、服装、空间关系、持物和状态变化。

用户不需要手写项目 JSON。Skill 会在内部工作目录登记视频哈希、实测时长、抽帧证据、镜头映射和审查状态。

## 处理方式

视频来源组和最终聚合建议是两件事：

- **来源组**表示一段已有视频应覆盖哪些连续脚本镜头，用于抽帧和审查；它不会因为省略参考图而删除镜头。
- **聚合建议**只在审查通过后产生，只合并相邻镜头，并保护首次出场、关键道具状态、空间变化、必要切镜和前后锚点。

每个镜头的证据状态分为：

- `matched`：已经定位到候选帧，不代表画面内容通过。
- `uncertain`：抽帧不足以确认，必须补查或标为待人工检查。
- `absent`：完整补查后仍未找到，不能用它批准省图。

组级审查一次覆盖整组，检查四类问题：

- **单镜头**：人物、场景、道具、动作和动作结果。
- **连续性**：身份、服装、位置、持物、左右手和状态承接。
- **整段故事**：是否漏镜、乱序或增加剧情，静音观看能否理解主要事件。
- **字幕**：是否出现字幕、文字或其他交付不允许的屏幕文本。

`ai_fill` 只表示“这一镜可以省掉独立参考图”的建议，原脚本镜头仍会保留。前后锚点没有可靠证据、镜头漏失或内容不确定时，Skill 会保留参考图并标记待检查。替换视频后，相关来源组需要重新抽帧和审查，其他有效结果可以复用。

## 输出

用户交付目录保持简洁：

```text
分镜说明.md
images/
  S01-...png
  S02-...png
  S03-...png
```

`分镜说明.md` 按原镜头顺序写清：

- 段落或镜头编号
- 计划时长
- 分镜缩略图或 `AI 补足`/待检查占位
- 原脚本描述
- 图片来自哪一帧，以及简短的匹配或保留理由

最终不交付视频、HTML、项目清单、内部 JSON、抽帧日志或审查记录。未能从视频确认的动作、转场或内容会明确写成“待人工检查”，不会伪称已通过。

## 在 Codex 中使用

将仓库中的 `ai-storyboard-previs` 文件夹安装到个人技能目录：

```text
Windows: %USERPROFILE%\.codex\skills\ai-storyboard-previs
macOS/Linux: ~/.codex/skills/ai-storyboard-previs
```

然后在 Codex 中说明材料位置，例如：

```text
使用 $ai-storyboard-previs，读取这个视频、分镜脚本和资产图。
请抽帧匹配并审查人物、场景、道具、动作、连续性和字幕，
再给出相邻镜头聚合与 ai_fill 建议，只交付分镜图片和易读的 Markdown。
```

如果用户明确要求真实生成、补图或局部重生成，才读取兼容的生成规则；模型、图片数量、时长和预算由运行配置决定，不写死在分镜脚本中。

## 本地开发与检查

开发检查需要 Python 3.10+、Pillow、FFmpeg 和 FFprobe。FFmpeg/FFprobe 应在 `PATH` 中，也可以用 `FFMPEG`、`FFPROBE` 环境变量指定完整路径。

```powershell
python -m pip install -r requirements-dev.txt
powershell -ExecutionPolicy Bypass -File tests/run_checks.ps1
```

检查包括单元测试、合成视频抽帧与模拟审查流程；不会调用付费模型，也不宣称验证了真实模型的视觉质量。若本机安装了 Codex 的 `skill-creator`，检查脚本还会运行其技能结构校验器。

## 目录

```text
ai-storyboard-previs/  Skill 入口、规则、示例数据和工具脚本
tests/                 行为测试、媒体测试和检查脚本
requirements-dev.txt   开发与测试依赖
```

仓库不会提交用户资产、实际视频、抽帧结果、缓存、私密配置、二进制媒体工具或历史演示产物；这些路径已写入 `.gitignore`。
