# AI 分镜图预演与自迭代 Skill

`ai-storyboard-previs` 把角色、场景、道具资产图和有序分镜脚本，整理为一套可检查的分镜图。它会先用快速切镜视频取得候选画面，再逐镜选图、检查连续性，并只修复有问题的镜头。

视频是中间素材，最终交付是分镜图片和一份用户能直接阅读的 `分镜说明.md`。不交付视频、HTML、项目清单或内部审查记录。

## 它解决什么问题

当一个故事里有人物出场、道具交接、动作结果和场景切换时，单独生成每张分镜图常会出现人物变脸、道具消失、左右手混乱或漏镜。这个 Skill 会保留原始镜头编号和顺序，把已知的人物、道具和状态写成明确约束，再根据实际生成结果做局部处理。

它会：

- 根据相邻镜头和模型限制，将脚本分成可生成的视频组。
- 判断哪些输入参考图必须保留，哪些可以由模型补足。
- 生成快速硬切视频并从中匹配每个镜头的候选帧。
- 用脚本、资产和相邻镜头检查人物、场景、道具、关键动作和连续性。
- 对确认失败的镜头优先修图或补图；只有整组失配时才重生成该组。
- 输出按原镜头顺序排列的分镜图片与 Markdown 说明。

它不会把模型或接口成功当作视觉通过。动作、切镜或遮挡无法由抽帧确认时，会标为待人工检查。

## 需要准备什么

给 Skill 提供以下内容：

1. **资产图**：角色、场景和关键道具的图片，以及它们各自的简短说明。
2. **有序脚本**：每个镜头的编号、画面描述、时长，以及关键动作的前后结果。
3. **生成限制**：画幅、预算、最多提交次数；未提供时，由 Skill 先提出适合快速预演的安排。
4. **RunningHub 配置**：只有需要真实生成或修图时才需要。模型由运行时查询并确认，不固定写在 Skill 中。

一个简单脚本的写法：

```text
S01 门厅全景，黄外套女孩手持红挂件钥匙，蓝外套男孩站在木门旁。2 秒。
S02 手部特写，女孩把钥匙递向男孩。1.5 秒。
S03 中景，男孩接住钥匙，女孩松手；最后钥匙只在男孩手中。2 秒。
S04 门外，男孩拿着同一把钥匙走出木门。2 秒。
```

## 最终会得到什么

最终目录只包含：

```text
分镜说明.md
images/
  S01-...png
  S02-...png
  S03-...png
```

`分镜说明.md` 会按原镜头顺序展示每张图、脚本、计划时长和状态。没有单独图片的镜头仍会保留编号和剧情，并说明依据。内部工作文件、候选视频、抽帧证据和审查记录不会混入交付目录。

## 如何安装和使用

这是一个 Codex Skill。将仓库中的 `ai-storyboard-previs` 文件夹放到个人技能目录：

```text
Windows: %USERPROFILE%\.codex\skills\ai-storyboard-previs
macOS/Linux: ~/.codex/skills/ai-storyboard-previs
```

然后在 Codex 中这样请求：

```text
使用 $ai-storyboard-previs，根据我的资产图和有序分镜脚本制作分镜图。
视频只用于取图，最终交付图片和 Markdown。
```

Skill 会先确认镜头要求和分组，再执行真实生成。默认最多进行 3 轮付费修复，且遵守当次预算和提交次数；只重做受影响的镜头或视频组。达到限制后保留当前最佳结果，并说明尚待确认的画面。

## 给开发者的说明

运行本地检查前，需要：

- Python 3.10 或更高版本。
- `Pillow`，用于图片和测试夹具。
- FFmpeg 与 FFprobe，放入 `PATH`，用于媒体抽帧和媒体测试；也可用 `FFMPEG`、`FFPROBE` 环境变量指定完整路径。
- 安装本仓库的开发依赖：`python -m pip install -r requirements-dev.txt`。

运行检查：

```powershell
powershell -ExecutionPolicy Bypass -File tests/run_checks.ps1
```

该检查运行单元测试，并在本机存在 Codex 的 `skill-creator` 校验器时额外验证技能目录结构。测试使用合成媒体和模拟接口，仅验证数据、限额、恢复、文件关联和交付格式；不宣称已验证真实模型的视觉质量。

## 仓库结构

```text
ai-storyboard-previs/  Skill 本体：入口说明、规则、示例数据与脚本
tests/                 单元测试和可复现检查脚本
requirements-dev.txt   开发与测试所需的 Python 依赖
```

仓库刻意不包含用户资产、实际生成视频、抽帧结果、缓存、私密配置、二进制媒体工具和历史演示产物。
